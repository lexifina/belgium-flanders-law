# Vulnerabilities in Flemish law

**English** · [Nederlands](#nederlands)

The vulnerability detectors from [lexifina/global-law](https://github.com/lexifina/global-law/tree/main/vulnerabilities) look for mechanical mistakes in legislation: a rule applying "until" a date that has passed, a provision repealed before its replacement took effect, two amendments to the same provision on the same day, a rule in force before it was published.

**Placeholder.** The detectors have not been run on this repository yet. When they are, this page will give, as [serbia-law's](https://github.com/lexifina/serbia-law/tree/main/vulnerabilities) does, the flags by category, the ones a language model reviewed and those that survived, each checked by hand in this repository, with the data and the scripts in this folder.

A flag is a prompt to look, not legal advice, and nothing here has been tested in court.
